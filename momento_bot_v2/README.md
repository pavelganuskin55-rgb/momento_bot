# Бот и Mini App для цветочного магазина МОМЕНТО (v2)

Исправленный боевой комплект:
- `docs/index.html` + `docs/images/` — лёгкая витрина Mini App на чистом CSS (без тяжёлого base64 и сторонних CDN) с подгрузкой ассортимента и галочек наличия из Google Таблицы.
- `bot.py` — Telegram-бот на `aiogram 3` с приёмом заказов, HTML-экранированием, сохранением ссылок при смене статуса, записью и обновлением статусов в Google Таблице и базовым автоответчиком.
- `assortment_template.csv` — готовый шаблон листа «Ассортимент» для импорта в Google Таблицу.

## Шаг 1. Подключить Google Таблицу с галочками наличия

1. Создайте новую Google Таблицу и назовите первый лист `Ассортимент`.
2. Импортируйте в него файл `assortment_template.csv` (**Файл → Импортировать**).
3. Выделите столбец `in_stock` (со 2-й строки) и нажмите **Вставка → Чекбокс** — теперь продавец с телефона просто ставит/снимает галочки.
4. Опубликуйте лист для витрины: **Файл → Поделиться → Опубликовать в интернете**, выберите лист `Ассортимент` и формат **CSV**, скопируйте ссылку.
5. Вставьте эту ссылку в `docs/index.html` в поле `SHEET_CSV_URL` (внутри `const CONFIG = { ... }`), там же укажите реальный `PICKUP_ADDRESS` и цену доставки.

## Шаг 2. Выложить витрину (`docs/`) на GitHub Pages

1. Создайте репозиторий на GitHub (например, `momento`) и загрузите туда всю папку `docs/` (вместе с подпапкой `images/`).
2. В настройках репозитория откройте **Settings → Pages → Deploy from a branch**, выберите ветку `main` и папку `/docs` → **Save**.
3. Получите ссылку вида `https://ваш_ник.github.io/momento/`.

## Шаг 3. Запустить бота (`bot.py`)

1. Создайте бота в `@BotFather` (`/newbot`) и скопируйте `BOT_TOKEN`.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Скопируйте `.env.example` в `.env` и заполните:
   - `BOT_TOKEN` — токен от `@BotFather`
   - `WEBAPP_URL` — ссылка с GitHub Pages
   - `ADMIN_CHAT_ID` — ID рабочей группы флористов (добавьте бота в группу и напишите `/myid`)
4. Запустите бота:
   ```bash
   python bot.py
   ```

> **Важно про кнопку открытия:** бот открывает магазин через Reply-кнопку «Открыть магазин МОМЕНТО» внизу чата — именно через неё работает передача заказа `Telegram.WebApp.sendData()` без отдельного веб-сервера. Если в будущем захотите запуск через Menu Button (слева от поля ввода), потребуется поднять HTTP-эндпоинт на сервере.

## Шаг 4. Автозапись заказов и статусов в Google Таблицу

1. В [Google Cloud Console](https://console.cloud.google.com/) включите **Google Sheets API**, создайте сервисный аккаунт и скачайте ключ `credentials.json` рядом с `bot.py`.
2. В вашей Google Таблице выдайте права **Редактор** на email сервисного аккаунта.
3. Скопируйте ID таблицы (между `/d/` и `/edit` в адресной строке) в `SPREADSHEET_ID` в `.env` и перезапустите бота. Лист `Заказы` создастся автоматически при первом заказе, а кнопки статусов в чате будут обновлять столбец статуса прямо в таблице.
