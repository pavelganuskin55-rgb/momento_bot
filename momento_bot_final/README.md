# Бот и Mini App для цветочного магазина МОМЕНТО (v4)

Финальный комплект:
- `docs/index.html` + `docs/images/` — лёгкая витрина Mini App на чистом CSS с подгрузкой ассортимента и галочек наличия из Google Таблицы.
- `bot.py` — Telegram-бот (`aiogram 3`) со строгой валидацией заказов, пересчётом итога и доставки, защитой от потери заказов, строгим порядком статусов, фоновой записью в Google Таблицу (с таймаутом и повтором) и автоответчиком.
- `assortment_template.csv` — шаблон публичной таблицы ассортимента.
- `.gitignore` — защищает `.env`, `.env.*` и `credentials*.json` от попадания в GitHub.

## Важно про безопасность данных (2 разные таблицы!)

Создайте **две отдельные** Google Таблицы:
1. **Публичная таблица «Ассортимент»** — только товары, цены и галочки `in_stock`. Её лист публикуется в CSV для витрины.
2. **Приватная таблица «Заказы»** — здесь бот хранит имена, телефоны и адреса клиентов. **Никогда не публикуйте её в интернете!** Доступ даётся только владельцу и сервисному аккаунту бота.

*(Примечание: цены за позицию передаются из витрины, а бот пересчитывает итог и стоимость доставки. Флорист проверяет заказ глазами перед подтверждением).*

---

## Шаг 1. Настроить публичную таблицу «Ассортимент»

1. Создайте Google Таблицу и импортируйте `assortment_template.csv` (**Файл → Импортировать**).
2. Выделите столбец `in_stock` (со 2-й строки) → **Вставка → Чекбокс**.
3. **Файл → Поделиться → Опубликовать в интернете** → выберите **только лист с ассортиментом** и формат **CSV** → скопируйте ссылку.
4. Вставьте ссылку в `docs/index.html` в `SHEET_CSV_URL` (внутри `const CONFIG`). Убедитесь, что `DELIVERY_FEE`, `FREE_DELIVERY_FROM` и `PICKUP_ADDRESS` в `docs/index.html` совпадают со значениями в `.env`.
   *(Google кэширует опубликованный CSV на 1–5 минут, поэтому галочки обновляются с небольшой задержкой).*

## Шаг 2. Выложить витрину (`docs/`) в интернет

- **Netlify Drop (без вашего имени в домене):** перетащите папку `docs` на `https://app.netlify.com/drop` и переименуйте сайт (например, `momento-flo.netlify.app`).
- **GitHub Pages:** загрузите папку `docs/` в корень репозитория → **Settings → Pages → Branch: `main` / `/docs`**.

## Шаг 3. Настроить и запустить `bot.py`

1. Установите Python 3.10+ и зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Скопируйте `.env.example` в `.env` (убедитесь, что `.gitignore` лежит в корне репозитория с точкой в начале имени!).
3. Впишите в `.env`:
   - `BOT_TOKEN` — токен из `@BotFather`
   - `WEBAPP_URL` — ваша HTTPS-ссылка на витрину
   - `ADMIN_CHAT_ID` — ID группы флористов (добавьте бота в группу, запустите `python bot.py`, напишите в группе `/myid`, впишите ID в `.env` и перезапустите бота).
   - `MANAGER_USERNAME` — юзернейм флориста без `@` для прямых вопросов (по желанию).
   *(Если обычная группа позже станет супергруппой, Telegram поменяет её ID на `-100...` — тогда просто снова отправьте `/myid` и обновите `ADMIN_CHAT_ID` в `.env`).*
4. **Приватная таблица «Заказы» (по желанию):**
   - В Google Cloud Console включите **Google Sheets API**, создайте сервисный аккаунт, скачайте ключ и переименуйте его в `credentials.json` рядом с `bot.py`.
   - Создайте отдельную приватную Google Таблицу, выдайте права **Редактор** на email сервисного аккаунта и впишите ID таблицы в `ORDERS_SPREADSHEET_ID` в `.env`.

## Шаг 4. Круглосуточная работа 24/7 на VPS (`systemd`)

Бот должен быть запущен в **одном** экземпляре (две копии одновременно вызовут `TelegramConflictError`). На сервере Ubuntu создайте службу `/etc/systemd/system/momento.service`:

```ini
[Unit]
Description=Momento Flower Shop Telegram Bot
After=network.target

[Service]
Type=simple
WorkingDirectory=/root/momento
ExecStart=/root/momento/.venv/bin/python /root/momento/bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Запуск и автостарт:
```bash
sudo systemctl daemon-reload
sudo systemctl enable --now momento
sudo systemctl status momento
```
